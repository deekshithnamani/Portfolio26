# Slow ink homepage implementation plan

**Approved design:** Fine round ink grain over warm paper, concentrated along the lower-right and outer left edge. Preserve the existing content column and typography. Use shallow 28–36 second drift, a small delayed pointer response that settles after inactivity, a soft arrival, and a quieter mobile composition. Reduced motion remains still and hidden tabs pause animation.

**Implementation:** Replace the tiled geometric grain and traveling wave masks in src/index.css with a shared irregular dot tile and broad layered ribbon masks. Keep the effect procedural and independent of the generated concept image. Update motion tokens in src/tokens.css. Simplify DitherBackground to pointer response, idle settling, visibility pause, and cleanup. Document the final treatment in src/design/README.md.

**Validation:** Add behavioral tests for reduced motion, idle reset, hidden tabs, and unmount cleanup before changing interaction code. Run the focused tests, npm run verify, and git diff --check. Inspect the rendered homepage if browser access is available.
